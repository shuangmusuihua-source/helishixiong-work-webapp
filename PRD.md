## 1. 产品概述

### 1.1 产品定位

河狸师兄 是一款面向中文用户的智能幻灯片生成 Web 应用。用户通过输入话题、文本或上传文件，系统自动完成内容规划、大纲生成、主题选择，最终输出可独立运行的 HTML 幻灯片文件。

### 1.2 目标用户

| 用户群体 | 使用场景 | 核心需求 |
|----------|----------|----------|
| 商务人士 | 工作汇报、项目提案 | 快速生成专业幻灯片 |
| 产品经理 | 产品介绍、需求评审 | 结构化内容展示 |
| 数据分析师 | 数据报告、分析汇报 | 数据可视化呈现 |
| 市场运营 | 活动方案、竞品分析 | 对比分析展示 |
| 技术人员 | 技术分享、架构说明 | 架构图、流程图展示 |

### 1.3 核心价值

1. **效率提升**：从话题到幻灯片，分钟级完成
2. **专业设计**：预设主题模板，保证视觉质量
3. **灵活定制**：支持大纲编辑、主题切换、内容迭代
4. **独立输出**：单 HTML 文件，无需依赖即可运行

### 2.2 功能模块详解

#### 2.2.1 Step 1: 输入处理

**功能描述**

处理用户输入，支持三种输入方式，可选联网检索补充材料。

**输入类型判断逻辑**

| 输入类型 | 判断条件 | 处理方式 |
|----------|----------|----------|
| 话题 | 文本长度 < 50 字符 且 无换行符 | 自动联网检索 |
| 文本 | 文本长度 ≥ 50 或 含换行符/Markdown | 询问是否检索 |
| 文件 | .txt 或 .md 文件 | 读取内容后询问 |

#### 2.2.2 Step 2: 内容规划

**功能描述**

基于输入内容，AI 自动生成幻灯片大纲，用户可编辑确认。

**大纲结构**

```json
{
  "slides": [
    {
      "page_type": "cover",
      "title": "主标题",
      "subtitle": "副标题",
      "author": "演讲人（可选）",
      "date": "日期"
    },
    {
      "page_type": "content",
      "page_number": 1,
      "title": "页面标题",
      "content_type": "data-cards | data-chart | comparison-feature | comparison-table | timeline | architecture | quote | list | paragraph",
      "summary": "一句话总结",
      "content": {}
    }
  ]
}
```

**内容类型识别规则**

| 优先级 | 类型 | 识别特征 | 布局组件 |
|--------|------|----------|----------|
| 1 | data-cards | 多个关键指标展示 | 数据卡片 |
| 2 | data-chart | 趋势/分布可视化 | ECharts 图表 + 左侧说明 |
| 3 | comparison-feature | 两对象不同维度优势对比 | 左右对比卡片 |
| 4 | comparison-table | 多对象同维度数据对比 | 对比表格 |
| 5 | timeline | 时间节点、年份序列 | 水平时间轴 |
| 6 | architecture | 层级结构、架构描述 | 层级架构图 |
| 7 | quote | 引用符号、名人名言 | 引用块 |
| 8 | list | 列表项、要点 | 列表卡片 |
| 9 | paragraph | 纯文本段落 | 段落布局 |

**界面元素**

```
┌─────────────────────────────────────────────────────────────────┐
```

## 3. 非功能需求

```json
  }
```

### 6.3 主题迁移要求

为确保主题原样还原，需：

1. **完整复制** style.css，不做修改
2. **保留所有 CSS 变量**定义
3. **保留边缘高光效果**（::before 伪元素）
4. **保留毛玻璃效果**（backdrop-filter）
5. **保留动画定义**（@keyframes）
6. **字体文件**本地部署
